# Tiny stack virtual machine

Entry for the make.fun bounty [Build a tiny stack virtual machine](https://make.fun/bounty/tiny-stack-vm-01-run-20261122). `main.ts` (Node 22) is a from-scratch interpreter for the tiny stack ISA, with all ten traps. It answers all 40 instances in one deterministic run.
